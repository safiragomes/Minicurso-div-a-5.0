# Wrapped 2026 — minicurso <div>a

Página web (desktop) estilo "Spotify Wrapped" para alunas que nunca programaram. Código deve continuar simples (HTML + CSS básico), baseado no boilerplate do minicurso.

## Seções
1. Navbar escura: logo, links âncora (Início, Minhas músicas, Sobre mim, Minha era), botão de tema (dark-mode.js)
2. Apresentação: "Maysa's Wrapped 2026" + texto + botão + foto circular
3. Top 3 músicas: cards com número, capa do álbum, nome, artista e botão "Ouvir no YouTube"
4. Sobre mim: card "Minha personalidade" (70% café, 20% código, 10% sanidade) e card "Top 3 coisas que amo" (música, praia, tecnologia)
5. Minha era atual: "✨ tentando aprender frontend ✨"
6. Rodapé
